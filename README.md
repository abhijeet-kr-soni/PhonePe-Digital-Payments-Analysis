PhonePe Pulse Data Analysis

📊 Project Overview

This project performs an end-to-end exploratory data analysis of PhonePe Pulse data to understand digital payment activity across Indian states and districts.

The analysis examines transaction trends, user activity, device/brand usage, demographic characteristics, and relationships between population and transaction activity.

🎯 Objectives

The project aims to:

• Analyze transaction trends across years and quarters.
• Compare transaction activity across states and districts.
• Examine transaction types and payment behavior.
• Analyze registered users and app opens.
• Study device and brand usage patterns.
• Analyze district-level population and population density.
• Identify relationships between demographic characteristics and transaction activity.
• Derive actionable insights from the analysis.

🗂️ Dataset

The analysis uses the PhonePe Pulse dataset containing state-level and district-level transaction, user, device, and demographic information.

Main datasets used

• State Transaction and Users
• District Transaction and Users
• State Device Data
• District Demographics
• Transaction Type Data

🛠️ Technologies Used

• Python
• Pandas
• Matplotlib
• Jupyter Notebook

🔍 Analysis Performed

1. Data Exploration

• Inspected dataset structure and columns.
• Checked data types and missing values.
• Examined duplicate records and basic statistics.

2. Transaction Analysis

• Analyzed transaction volume and transaction amount.
• Examined yearly and quarterly trends.
• Compared transaction activity across states and districts.
• Calculated Average Transaction Value (ATV).

3. User Analysis

• Analyzed registered users and app opens.
• Examined user activity across states and time periods.

4. Device Analysis

• Analyzed device/brand usage across states.
• Calculated device usage ratios.

5. Demographic Analysis

• Analyzed population and population density at district level.
• Compared demographic characteristics with transaction activity.

6. Correlation Analysis

District-level demographic data was compared with aggregated transaction data using correlation analysis.

Key relationships examined:

• Population vs Total Transactions
• Population vs Total Amount
• Area vs Total Transactions
• Area vs Total Amount
• Density vs Total Transactions
• Density vs Total Amount

📈 Key Findings

• Overall transaction activity shows a strong upward trend over the available period.
• Transaction volume and transaction amount vary considerably across states and districts.
• Population and population density show positive relationships with transaction activity.
• Geographical area has a comparatively weaker relationship with transaction activity.
• Device and brand usage varies across states, indicating differences in digital-payment adoption patterns.

💡 Business Insights

The analysis suggests that population size and density can be useful indicators when examining digital-payment activity at the district level.

The findings can support:

• Market expansion analysis
• Digital-payment adoption studies
• Customer segmentation
• Regional performance analysis
• Infrastructure and service planning

Correlation results represent associations and should not be interpreted as proof of causation.
